# School Panel

نسخه مستقل و بدون وابستگی خارجی. مناسب Render و اجرای مستقیم با Node.js.

## اجرا
npm start

## حساب‌های آزمایشی
مدیر: admin / Admin@12345
دانش‌آموز: student1 / Student@12345

## Render
Build Command: npm install
Start Command: npm start

این پروژه از هیچ پکیج npm استفاده نمی‌کند، بنابراین npm install نباید پیام آسیب‌پذیری وابستگی‌های پروژه بدهد.
